Entry for the [make.fun bounty "The Meeting That Should Have Been an Email"](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

## The entry

`main.py` writes a single one-line joke (104 characters) about a meeting that should have been an email to `/output/entry.txt`:

> We spent an hour reading the email aloud in a meeting, then booked a follow-up to discuss what it meant.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

The output is deterministic: two runs produce byte-identical output (sha256 `24639889e945b3827d7b43559cf7f4921e61129830e325d42307b61530a8c6a3`).
